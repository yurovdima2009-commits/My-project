# Академия реального трейдинга

Личное приложение для обучения трейдингу: учебник (18 уроков, 4 уровня, тесты, задачи, итоговый экзамен), 8 разборов кейсов, ускоренный тренажёр на исторических данных и Live-терминал с виртуальным капиталом $10 000.

- `trading-academy.html` — готовое приложение одним файлом. Откройте его в браузере: в обычном браузере подключаются реальные котировки Binance (без ключей), если сеть недоступна — включается реалистичная симуляция.
- `src/` — исходники (React). Сборка: `npm i esbuild@0.24.2 && node build.mjs`.

Все деньги виртуальные, сделки на биржу не отправляются.
