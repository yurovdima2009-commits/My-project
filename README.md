# Мой день

Личное приложение для заметок, целей на день, задач и планов. Работает в браузере и офлайн, его можно установить на телефон как обычное приложение.

## Что умеет

- **Сегодня** — до 3 главных целей дня, задачи на день (плюс просроченные), прогресс дня, настроение и «итог дня». Стрелками можно листать дни.
- **Задачи** — с датой и приоритетом (обычная / важная / срочная), группировка по дням, «Без даты», просроченные, выполненные. Нажми на задачу, чтобы изменить её или добавить описание.
- **Заметки** — с тегами, поиском и закреплением.
- **Планы** — цели на неделю / месяц / год / мечты, с шагами, сроком и прогресс-баром.
- **Настройки (⚙️)** — светлая/тёмная тема, статистика, резервная копия в файл и восстановление.

Данные хранятся только на твоём устройстве (localStorage). Время от времени делай резервную копию через ⚙️.

## Как запустить

Самое простое — включить GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка с этим кодом, папка `/ (root)`. Приложение будет доступно по адресу `https://<логин>.github.io/My-project/`.

На телефоне открой этот адрес и выбери «Добавить на главный экран» (iPhone: Поделиться → На экран «Домой»; Android: меню ⋮ → Установить приложение).

Локально: `python3 -m http.server` в этой папке и открыть http://localhost:8000.
