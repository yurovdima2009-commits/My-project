# AQUAVAPOR

Investor presentation for AQUAVAPOR, a private floating sauna at sea off the Dubai coast.

- `index.html` — the presentation (three.js 0.160 + GSAP from CDN). Arrow keys, space, wheel, swipe or click; F for full screen.
- `assets/` — the brand logo (mark, wordmark, hull lockup) and a generated sea normal map.
- `src/` — sources `index.html` is built from: `python3 src/build.py`.

The platform, its interior, the sea, sky, clouds and the Dubai coastline are modelled in code.
All figures come from the investor deck and are projections, not guarantees.
