# ЛидРадар — поиск клиентов для фрилансера

Приложение для себя: находит местный бизнес на карте, показывает, у кого нет сайта, ведёт базу клиентов, готовит сообщения и собирает для каждого клиента демо-сайт со ссылкой.

## Что умеет

- **Поиск.** Любые города и около 90 категорий в 15 сферах (еда, красота, авто, медицина и другие), плюс поиск по своему слову в названии. Данные берутся из OpenStreetMap.
- **Оценка клиента от 0 до 100.** Нет сайта или есть только соцсети, есть мобильный телефон — выше. Сети (у них свои маркетологи) — ниже.
- **Карточка клиента.** Кнопки WhatsApp, Telegram, Viber, Instagram, VK и звонка. Готовое сообщение, «✨ Сделать личным» через ИИ, ссылки на 2ГИС и Яндекс Карты, чтобы найти недостающие контакты.
- **База (CRM).** Статусы «Новый → В очереди → Написал → Ответил → Интерес → Клиент / Отказ», заметки, напоминания, история, выгрузка в Excel.
- **Рассылка.** Проходите очередь по одному: текст уже готов, жмёте WhatsApp, отправляете, потом «✓ Отправил, дальше». Через 3 дня приложение напомнит написать ещё раз.
- **Демо-сайты.** Claude пишет тексты под конкретное заведение, приложение собирает страницу в одном из 5 стилей, с корзиной и заказом в WhatsApp. Ссылку можно сразу отправить владельцу.
- **Шаблоны сообщений** с переменными `{название}`, `{город}`, `{демо}`, `{моё_имя}`, `{цена}` и другими.
- **Карта** всех найденных мест, стоп-лист, резервная копия, светлая и тёмная тема, работа на телефоне.

## Как запустить

Включите GitHub Pages: **Settings → Pages → Branch** → выберите ветку и папку `/ (root)` → **Save**.
Через пару минут приложение откроется по адресу `https://yurovdima2009-commits.github.io/My-project/lidradar/`.
По этому же адресу будут открываться демо-ссылки для клиентов (`demo.html#…`).

Можно и просто открыть `index.html` в браузере, но тогда ссылки на демо всё равно ведут на GitHub Pages.

## ИИ

- **Без ключа.** Кнопка «Скопировать промт» → вставьте его в claude.ai → скопируйте ответ обратно. Бесплатно.
- **С ключом.** Вставьте API-ключ Anthropic в «Настройках», и тексты будут писаться в один клик. Ключ хранится только в вашем браузере.

## Файлы

- (в папке `lidradar/`) `index.html`, `css/app.css`, `js/app.js` — само приложение
- (в папке `lidradar/`) `js/data.js` — категории для поиска, статусы, шаблоны сообщений (их легко дополнять)
- (в папке `lidradar/`) `js/ai.js` — работа с Claude и промты
- (в папке `lidradar/`) `js/demo-render.js`, `demo.html` — демо-сайты для клиентов
- (в папке `lidradar/`) `kafe-radar.html` — первая версия (карта кафе Хабаровска)

Все данные (база, заметки, ключ) хранятся в браузере. Делайте «Сохранить резервную копию» в «Настройках».
