# EROFEY CYBER ARENA — сайт компьютерного клуба (Хабаровск)

Лендинг киберклуба на базе «Ерофей Арены». Тёмная неоновая сине-фиолетовая тема, интерактивный 3D-геймпад на первом экране.

## Как открыть

Сайт статический, сборка не нужна. Из-за ES-модулей его нужно открывать через локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Структура

- `index.html` — разметка всех секций (hero с оффером, преимущества, зоны, тарифы, железо, игры, турниры, бронирование, FAQ, контакты)
- `css/style.css` — стили, цветовые токены в `:root`, HUD-рамки со скошенными углами, адаптив
- `js/main.js` — табы зон, подсветка текущего тарифа (по хабаровскому времени), таймер акции, калькулятор брони, маска телефона
- `js/gamepad.js` — 3D-геймпад на three.js
- `vendor/three/` — локальная копия three.js r160 (MIT)

## 3D-геймпад

- наклоняется за курсором, «парит» в воздухе;
- тянуть мышью/пальцем — вращение с инерцией;
- клик по кнопкам △ ○ ✕ □, крестовине, стикам, тачпаду, L1/R1/L2/R2 — нажатие, вспышка, частицы, лог ввода;
- клавиатура: `WASD` — левый стик, `I J K L` — кнопки, стрелки — крестовина, `Q/E` — бамперы;
- можно подключить настоящий геймпад — модель повторяет нажатия;
- пасхалка: Konami-код (↑↑↓↓←→←→ ○ ✕ или B A на клавиатуре).

## Что заменить на реальные данные

Цены, количество ПК, конфигурации, телефон, e-mail и ссылки на соцсети — демонстрационные.
Цены меняются в `js/main.js` (объекты `RATES` и `ZONES`) и в `index.html` (секция `#prices`).
Фото подключены с Unsplash — замените на фотографии клуба. Если фото не загрузится, показывается градиентная заглушка.
Форма брони пока показывает уведомление — для реальных заявок подключите отправку (например, в Telegram-бота или CRM).
