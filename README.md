# ☕ Кафе-радар · Хабаровск

Личное приложение для поиска клиентов среди кафе, кофеен, ресторанов и баров Хабаровска.

## Что умеет
- Карта всех заведений города (данные OpenStreetMap, загружаются автоматически)
- Статус для каждого места: Не обработан → В планах → Связался → Интерес → Клиент / Отказ
- Заметки, контактное лицо, свой телефон, дата напоминания, история статусов
- Поиск и фильтры по статусу, типу заведения, наличию телефона
- Кнопки «Позвонить», «2ГИС», «Яндекс Карты», «Маршрут»
- Свои точки на карте (кнопка «＋ Место»)
- Выгрузка в Excel (CSV) и резервная копия в файл
- Светлая и тёмная тема, работает на телефоне

## Как открыть
Скачайте `index.html` и откройте его в браузере — больше ничего не нужно.

Или включите GitHub Pages (Settings → Pages → ветка с файлом), и приложение будет доступно по ссылке.

Все ваши заметки хранятся в этом браузере. Периодически делайте «Сохранить резервную копию» в меню ⋯.
