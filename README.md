# AQUAVAPOR

Investor presentation for AQUAVAPOR, a private floating sauna at sea off the Dubai coast.

- `index.html` — the presentation (three.js 0.160 + GSAP from CDN). Arrow keys, space, wheel, swipe or click to navigate; F for full screen.
- `assets/waternormals.jpg` — procedurally generated normal map for the sea.
- `src/` — sources `index.html` is built from: `python3 src/build.py src`.

The 3D platform, interior, sea, sky and Dubai coastline are all modelled in code; no photos are used.
All figures come from the investor deck and are projections, not guarantees.
