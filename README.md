# Лидоискатель · Хабаровск

Приложение для поиска клиентов веб-студии: находит заведения Хабаровска
(кафе, салоны, автосервисы, клиники и т.д.) и показывает, **у кого нет сайта** —
это самые горячие потенциальные клиенты.

## Возможности
- 🔎 Поиск по 9 сферам бизнеса (данные OpenStreetMap, бесплатно, без ключей)
- 🎯 Оценка «шанса продажи» 0–100: нет сайта, есть телефон, не сетевая компания и т.д.
- 🗺 Карта с цветными метками: красный — нет сайта, жёлтый — только соцсети, зелёный — сайт есть
- 📋 Мини-CRM «Мои клиенты»: статусы (новый → написал → интерес → сделка), заметки, экспорт в CSV/Excel
- ✍️ Готовые тексты: короткое сообщение, сообщение с выгодами, скрипт звонка + кнопка WhatsApp
- 🔗 Быстрые ссылки на 2ГИС и Яндекс Карты, чтобы проверить контакты

## Как запустить
Просто открой `index.html` в браузере. Список клиентов хранится в этом браузере.

Чтобы открыть с телефона — включи GitHub Pages: Settings → Pages → Branch.

## Важно
OpenStreetMap знает не все заведения и не все телефоны. Всегда сверяй контакты в 2ГИС
(кнопка на карточке) перед звонком.
